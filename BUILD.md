# Trading Research — build pipeline

## Cloudflare Workers Builds

Production branch: `main`

Build command:

```text
npm run build
```

Production deploy command:

```text
npx wrangler deploy
```

Non-production / preview command:

```text
npx wrangler versions upload
```

Root directory: `/`

The build step is required because `wrangler.jsonc` serves static assets from `./dist`, and `dist/` is generated by `npm run build`.

## Local validation

```text
npm.cmd run prebuild
npm.cmd run build
```

Do not promote a consolidation branch to production until CI, Cloudflare preview build, and the manual smoke test have passed.
